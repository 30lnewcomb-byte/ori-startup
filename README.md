# Ori Startup

A minimal charcoal-themed Ori startup page with Ori's custom font references and a rotating pool of 103 greetings.

## File

- `ori-start.html` — standalone startup page. Greeting selection is randomized and stored locally in the browser to avoid repeating greetings until the pool cycles through.

## Notes

- The greeting history is local to this website's browser origin. It is not shared automatically with Ori Platform.
- The chat composer is a front-end placeholder and does not send messages to Ori's backend.
